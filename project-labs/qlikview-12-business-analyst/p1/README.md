# Multi-industry KPI dashboard

**Certification:** QlikView 12 Business Analyst (QVBA) (Qlik)
**Project 1 of 5**

> Build interactive dashboards across banking/retail/insurance KPIs.

![Architecture diagram](https://amandbohra.github.io/portfolio/study/projects/qlikview-12-business-analyst-1.svg)

## Architecture & data model
Focused dashboards with KPI text objects, comparison charts, list boxes, current-selections box, and bookmarks.

## Concepts covered
- **Chart selection** — Pick visuals to fit KPIs across banking/retail/insurance.
- **Dimensions & expressions** — Build measures from aggregation expressions over dimensions.
- **List boxes & current selections** — Selection objects and a Current Selections box for context.
- **Bookmarks** — Save and share specific filtered views.
- **UX best practices** — Consistent formatting, clear titles, focused sheets.

## Implementation steps
1. Design focused sheets with KPI objects and comparison charts.
2. Add list boxes and a Current Selections box.
3. Save bookmarks for common views.
4. Apply consistent formatting/conditional colors.

## Outcomes
- Clear multi-industry dashboards.
- Easy navigation.
- Shareable views.

## Tech stack
`QlikView` · `Charts`
