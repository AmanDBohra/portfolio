# Guided storytelling & KPI polish

**Certification:** QlikView 12 Business Analyst (QVBA) (Qlik)
**Project 5 of 5**

> Make dashboards executive-ready and easy to read.

![Architecture diagram](https://amandbohra.github.io/portfolio/study/projects/qlikview-12-business-analyst-5.svg)

## Architecture & data model
Executive-ready dashboards with traffic-light coloring, clean formats, sparklines, dynamic titles, and conditional show.

## Concepts covered
- **Conditional coloring (traffic lights)** — Color measures by status vs target.
- **Number formatting (num/money)** — Readable units, separators, decimals.
- **Sparklines** — Mini trends inside tables for context.
- **Dynamic titles (GetCurrentSelections)** — Titles reflecting current selections.
- **Show conditions** — Reveal detail objects only when relevant.

## Implementation steps
1. Add traffic-light coloring vs targets and clean number formats.
2. Embed sparklines for trend context in tables.
3. Build dynamic titles from current selections.
4. Use show conditions to reveal detail when relevant.

## Outcomes
- At-a-glance status.
- Readable KPIs.
- Guided, uncluttered dashboards.

## Tech stack
`QlikView` · `Expressions`

## Why this project (profile relevance)
Polished, guided dashboards communicate status at a glance.
