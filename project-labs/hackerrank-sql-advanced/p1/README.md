# Retail sales reporting queries

**Certification:** SQL (Advanced) (HackerRank)
**Project 1 of 5**

> Write the join/aggregation SQL layer a BI dashboard would sit on top of, for a retail transactions table (Invoice, Product, Quantity, UnitPrice, Country, InvoiceDate).

![Architecture diagram](https://amandbohra.github.io/portfolio/study/projects/hackerrank-sql-advanced-1.svg)

## Concepts covered
- **INNER/LEFT JOIN**
- **GROUP BY / HAVING**
- **Aggregate functions**
- **Date functions**

## Tech stack
`SQL (SQLite/PostgreSQL syntax)` · `CTEs`

## Why this project (profile relevance)
The exact reporting layer behind the FMCG Retail Sales Analysis dissertation and the general BI dashboards on this site.

## Run it
Open `notebook.ipynb` — it spins up an in-memory SQLite database with synthetic sample data and runs the actual SQL for this project, so it's runnable with just Python's built-in `sqlite3` module (no server setup required).
