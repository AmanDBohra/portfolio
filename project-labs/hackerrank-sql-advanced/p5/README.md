# Query performance tuning case study

**Certification:** SQL (Advanced) (HackerRank)
**Project 5 of 5**

> Take a slow, unindexed query against a large transactions table and demonstrate the indexing/rewrite that fixes it.

![Architecture diagram](https://amandbohra.github.io/portfolio/study/projects/hackerrank-sql-advanced-5.svg)

## Concepts covered
- **Indexes**
- **EXPLAIN / query plans**
- **Full table scan vs index seek**
- **Rewriting correlated subqueries as joins**

## Tech stack
`SQL` · `EXPLAIN`

## Why this project (profile relevance)
The optimization judgment that separates a correct query from a production-ready one — same discipline applied across every BI/SQL engagement on this site.

## Run it
Open `notebook.ipynb` — it spins up an in-memory SQLite database with synthetic sample data and runs the actual SQL for this project, so it's runnable with just Python's built-in `sqlite3` module (no server setup required).
