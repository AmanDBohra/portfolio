# Organizational hierarchy analysis via self-join

**Certification:** SQL (Advanced) (HackerRank)
**Project 2 of 5**

> Answer 'who earns more than their manager' and reporting-chain questions on an Employees table with a manager_id foreign key to itself.

![Architecture diagram](https://amandbohra.github.io/portfolio/study/projects/hackerrank-sql-advanced-2.svg)

## Concepts covered
- **Self-join**
- **Correlated subqueries**
- **NULL handling**

## Tech stack
`SQL`

## Why this project (profile relevance)
The same self-join pattern used for any manager/rollup or parent-child reporting structure in enterprise data.

## Run it
Open `notebook.ipynb` — it spins up an in-memory SQLite database with synthetic sample data and runs the actual SQL for this project, so it's runnable with just Python's built-in `sqlite3` module (no server setup required).
