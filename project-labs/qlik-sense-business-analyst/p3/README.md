# Master items & governance

**Certification:** Qlik Sense Business Analyst (QSBA) (Qlik)
**Project 3 of 5**

> Standardize definitions across the app.

![Architecture diagram](https://amandbohra.github.io/portfolio/study/projects/qlik-sense-business-analyst-3.svg)

## Architecture & data model
A master-items library (dimensions, measures, visuals) governs the app so every sheet uses consistent definitions.

## Concepts covered
- **Master dimensions** — Reusable, governed grouping fields (incl. drill-down hierarchies).
- **Master measures** — One approved definition of each metric reused everywhere.
- **Master visualizations** — Reusable approved charts for consistency.
- **Drill-down dimensions** — Hierarchies (Country>Region>City) that drill as users select.
- **Consistency** — Governed definitions prevent conflicting metric variants.

## Implementation steps
1. Create master measures for official metrics.
2. Define drill-down master dimensions.
3. Reuse master visualizations.
4. Document definitions for the team.

## Outcomes
- Consistent metrics across sheets.
- Faster app building.
- Governed self-service.

## Tech stack
`Qlik Sense` · `Master items`

## Why this project (profile relevance)
Governed self-service keeps metrics consistent across teams.
