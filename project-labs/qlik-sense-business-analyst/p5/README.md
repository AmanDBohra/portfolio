# Storytelling & what-if analysis

**Certification:** Qlik Sense Business Analyst (QSBA) (Qlik)
**Project 5 of 5**

> Communicate insight and enable scenario exploration.

![Architecture diagram](https://amandbohra.github.io/portfolio/study/projects/qlik-sense-business-analyst-5.svg)

## Architecture & data model
A story assembled from snapshots plus a what-if variable input and status coloring communicates and explores insight.

## Concepts covered
- **Stories & snapshots** — Capture chart states into a guided narrative for stakeholders.
- **Variable input (what-if)** — Input-controlled variables let users test scenarios.
- **Reference lines** — Dynamic benchmarks (avg/target) for context.
- **Conditional coloring** — Data-driven color to flag status vs target.
- **Accessibility** — Not-color-only encoding and sufficient contrast.

## Implementation steps
1. Capture snapshots into a guided story.
2. Add a variable-driven what-if input.
3. Use reference lines and conditional colors.
4. Ensure accessible (not color-only) encoding.

## Outcomes
- Compelling data storytelling.
- Scenario exploration.
- Accessible visuals.

`Qlik Sense` · `Stories` · `Variables`
