# Executive KPI app design

**Certification:** Qlik Sense Business Analyst (QSBA) (Qlik)
**Project 1 of 5**

> Design a focused app answering leadership's key questions.

![Architecture diagram](https://amandbohra.github.io/portfolio/study/projects/qlik-sense-business-analyst-1.svg)

## Architecture & data model
A focused app: KPI-led overview sheet, trend/comparison sheets, and filter panes for exploration.

## Concepts covered
- **Dimensions vs measures** — Dimensions group (by what); measures aggregate (how much).
- **Chart selection** — Pick the visual by question: line (trend), bar (compare), KPI (headline).
- **KPI objects** — Show headline metrics vs targets with conditional color.
- **App/sheet structure** — Organize sheets to mirror how users make decisions.
- **UX best practices** — Focused, uncluttered sheets that guide the eye.

## Implementation steps
1. Translate questions into KPIs and a sheet layout.
2. Lead with KPI objects; add trend/comparison charts.
3. Keep sheets focused; add filter panes.
4. Apply consistent formatting.

## Outcomes
- Executive-ready dashboard.
- Fast comprehension.
- Guided exploration.
