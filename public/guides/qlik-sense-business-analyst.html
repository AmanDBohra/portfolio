Qlik Sense Business Analyst (QSBA) — Study Guide

Designing effective Qlik Sense apps: choosing visualizations, building dimensions/measures and master items, writing set-analysis expressions, and applying UX best practices and storytelling.

~50 questions · 120 minutes · scenario-based on app design and analysis · passing per Qlik scoring.

What it is

The Qlik Sense Business Analyst (QSBA) validates the ability to design effective Qlik Sense apps for analysis: choosing visualizations, building dimensions/measures and master items, writing set-analysis expressions, applying selections and filtering, and communicating insight through dashboards and stories.

Where the Data Architect builds the data layer, the Business Analyst builds the analytical and visual layer — turning a governed data model into clear, decision-ready analysis.

Where it's used

  • Roles: BI/Business Analyst, Qlik App Designer, Analytics Consultant.
  • On the job: designing sheets and KPIs, writing set analysis for comparisons and % of total, creating master items for consistency, and building data stories.
  • Career value: validates the front-end analytics and UX skills that make Qlik apps genuinely useful to the business.
  • For this portfolio: reflects the dashboard-design and data-storytelling side of BI delivery.

In plain English

  • A dimension is the 'by what' (by product, by month); a measure is the 'how much' (sum of sales). Charts are just dimensions × measures.
  • Set analysis is telling one chart 'ignore what the user selected and show me 2024 anyway' — a filter that lives inside the formula.
  • The green/white/grey colors are Qlik's superpower: green = you picked it, white = still possible, grey = ruled out. It shows relationships instantly.
  • Master items are the 'house recipe' for a measure — define 'Revenue' once so every chart uses the exact same definition.

Exam shortcut tricks

  1. Set analysis identifiers: $ = current selection, 1 = ALL records (ignore selection). Modifiers in <> add/override/clear fields. Sum({1} Sales) = grand total.
  2. Clear one filter: <Field=> (empty). Set a value: <Year={2024}>. Exclude: <Region-={'East'}>. Memorize this syntax.
  3. Master measures = consistency + governance (one official definition). Expect a question on why to use them.
  4. Aggr() = nested aggregation over a virtual dimension: Avg(Aggr(Sum(Sales),Customer)) = average per customer. It's the tool for 'average of a total.'
  5. Chart choice: line = trend, bar = compare, KPI = headline, pie = few-part share, scatter = correlation.
  6. % of total that ignores selection → set analysis in the denominator (e.g., {1} or cleared fields), not a plain divide.
  7. Green/White/Grey meaning is frequently tested: selected / possible / excluded.

Study roadmap

  1. Requirements & app design — translating business questions into sheets, KPIs, and navigation.
  2. Dimensions vs measures — dimensions group data (categorical); measures aggregate (Sum, Count, Avg).
  3. Visualization selection — choose the right chart for the question (trend, comparison, part-to-whole, distribution).
  4. Master items — reusable dimensions, measures, and visualizations for consistency and governance.
  5. Set analysis — expression-level selections that override or modify the current selection state.
  6. Selections & filtering — selection states (green/white/grey) and filter panes.
  7. Storytelling & dashboards — snapshots, stories, and layout best practices.
  8. Accessibility & performance — clean, focused sheets that answer decisions.

Study notes

Dimensions & measures

  • Dimension = the 'by what' (categorical field you group/slice by).
  • Measure = an aggregation expression (Sum(Sales), Count(distinct Customer)).
  • Master items store approved dimensions/measures/visuals so every designer uses consistent definitions.

Set analysis

  • Set analysis defines a set of records for an aggregation independent of current selections: Sum({<Year={2024}>} Sales).
  • $ = current selection; 1 = all records ignoring selection. Modifiers in <> add/override field selections.
  • Common pattern: year-over-year, % of total, or 'ignore this filter' calculations.

Selection states

  • Green = selected; White = possible (associated) values; Grey = excluded (not associated).
  • The associative model shows what's related and what's excluded after a selection — a key analysis feature.

Visualization choice

  • Line for trends over time; bar for category comparison; combo for measure + rate; KPI for headline numbers; pie sparingly for part-to-whole.
  • Keep sheets focused: lead with the decision, avoid clutter.

Practice questions (100)

1. In Qlik Sense, which is a dimension rather than a measure?

  • A. Sum(Sales)
  • B. Product Category ✓
  • C. Avg(Price)
  • D. Count(OrderID)

Explanation: A dimension is a categorical field you group or slice by — 'Product Category'. Measures are aggregation expressions like Sum(Sales), Avg(Price), or Count(OrderID).

2. What is the main benefit of master items?

  • A. They speed up data loading
  • B. They provide reusable, governed definitions of dimensions/measures/visuals for consistency ✓
  • C. They encrypt the app
  • D. They replace set analysis

Explanation: Master items centralize approved definitions (e.g., one official 'Revenue' measure) so all sheets and designers reuse the same logic — ensuring consistency and easier maintenance.

3. What does the set-analysis expression Sum({<Year={2024}>} Sales) return?

  • A. Sales for the current selection only
  • B. Sales for Year 2024 regardless of the current Year selection ✓
  • C. All sales ever
  • D. An error

Explanation: The set modifier <Year={2024}> overrides the Year selection so the aggregation returns 2024 sales even if the user has selected a different year — a core set-analysis pattern for fixed comparisons.

4. In set analysis, what does the identifier '1' represent (e.g., Sum({1} Sales))?

  • A. The current selection
  • B. The full set of all records, ignoring current selections ✓
  • C. Only the first row
  • D. The previous year

Explanation: '1' represents all records in the app ignoring any selections, while '$' represents the current selection. Sum({1} Sales) gives the grand total regardless of what the user has filtered.

5. After a selection, what does a GREY value indicate in Qlik's associative model?

  • A. It is selected
  • B. It is an associated possible value
  • C. It is excluded (not associated with the selection) ✓
  • D. It is a calculated field

Explanation: Grey = excluded: values not associated with the current selection. Green = selected values; White = possible (still-associated) values. This color logic reveals relationships and gaps in the data.

6. Which visualization best shows a single headline KPI against a target?

  • A. Scatter plot
  • B. KPI object ✓
  • C. Filter pane
  • D. Treemap

Explanation: The KPI object displays one or two key measures prominently (optionally with conditional colors vs a target) — ideal for headline metrics at the top of a sheet.

7. To compare a measure across many categories, which chart is most appropriate?

  • A. Pie chart
  • B. Bar chart ✓
  • C. Line chart
  • D. Gauge

Explanation: A bar chart is best for comparing a measure across discrete categories — lengths are easy to compare. Pie charts become unreadable with many categories, and lines imply continuity/trend.

8. What is a Qlik Sense 'story' used for?

  • A. Loading data incrementally
  • B. Presenting insights via snapshots and narrative slides built from app visualizations ✓
  • C. Defining Section Access
  • D. Creating QVDs

Explanation: Stories let analysts capture snapshots of visualizations and assemble them into a guided, presentation-style narrative to communicate insights to stakeholders.

9. A user wants '% of total' that ignores the current category selection. Which technique is required?

  • A. A calculated dimension
  • B. Set analysis to control the aggregation's selection scope ✓
  • C. A QVD load
  • D. Section Access

Explanation: Computing a percentage of an unfiltered or differently-filtered total requires set analysis (e.g., using {1} or a modified set) so the denominator ignores or overrides the current selection.

10. Which is a UX best practice for a Qlik Sense sheet?

  • A. Put every available measure on one sheet
  • B. Lead with the key decision/metric and keep the sheet focused and uncluttered ✓
  • C. Avoid master items
  • D. Use only pie charts

Explanation: Effective sheets are focused: surface the most important metrics first, group related content, and avoid clutter so users can make decisions quickly. Overloading a sheet harms comprehension.

11. A calculated dimension differs from a master dimension in that it:

  • A. Is always faster
  • B. Is defined with an expression on the fly rather than reused from the library ✓
  • C. Cannot be used in charts
  • D. Requires Section Access

Explanation: A calculated dimension uses an expression (e.g., =If(...)) evaluated per chart. Master dimensions are governed, reusable definitions in the library — preferred for consistency.

12. The expression Count(DISTINCT CustomerID) returns:

  • A. Total order rows
  • B. The number of unique customers ✓
  • C. Sum of IDs
  • D. The average

Explanation: Count(DISTINCT CustomerID) counts unique customer values, whereas Count(CustomerID) counts all non-null occurrences (rows).

13. Set analysis Sum({<Product={'A','B'}>} Sales) returns sales for:

  • A. Only the current selection
  • B. Products A and B, overriding the Product selection ✓
  • C. All products
  • D. No products

Explanation: The modifier sets Product to {'A','B'}, overriding any current Product selection so the aggregation covers exactly those products regardless of what the user selected.

14. Which object is best for letting users make selections on a field?

  • A. Filter pane ✓
  • B. KPI object
  • C. Text & image
  • D. Gauge

Explanation: A filter pane exposes one or more fields for selection, driving the associative filtering across the app. KPI/gauge/text objects display values, not selection controls.

15. A combo chart is useful when you need to:

  • A. Show two measures with different scales (e.g., bars for value, line for %) ✓
  • B. Show a single number
  • C. List raw rows
  • D. Replace a filter pane

Explanation: A combo chart overlays bars and a line, ideal for plotting a magnitude measure alongside a rate/percentage on a secondary axis in one view.

16. The Alternate states feature enables:

  • A. Encryption
  • B. Comparing different selection sets side by side within one app ✓
  • C. Faster loading
  • D. Section Access

Explanation: Alternate states let different objects respond to independent selection sets, so you can compare, say, two product groups or time periods simultaneously in the same app.

17. Dollar-sign expansion $(=Max(Year)) in an expression:

  • A. Is a comment
  • B. Evaluates the inner expression first and substitutes its result ✓
  • C. Loads a QVD
  • D. Creates a master item

Explanation: $(=expression) performs dollar-sign expansion — the inner expression is evaluated and its value substituted into the outer expression, commonly used to make set analysis dynamic (e.g., latest year).

18. Which chart is most appropriate to compare parts of a whole across several categories over time?

  • A. Stacked bar chart ✓
  • B. Single KPI
  • C. Gauge
  • D. Pie chart

Explanation: A stacked bar chart shows composition within each category and how totals compare across categories/time. A pie only handles one whole at a point in time.

19. To display 'sales this year vs last year' in one chart, you would use:

  • A. Two measures with set analysis fixing each year ✓
  • B. Two separate apps
  • C. A filter pane only
  • D. Section Access

Explanation: Add two measures, each using set analysis to fix its year (current vs current-1), so the chart shows both regardless of the user's year selection.

20. A master measure improves governance by:

  • A. Encrypting the app
  • B. Providing one approved definition of a metric reused across all charts ✓
  • C. Speeding up loads
  • D. Creating QVDs

Explanation: Master measures centralize a metric's definition (e.g., official 'Margin %'), so every visual uses the same logic — reducing inconsistency and maintenance effort.

21. The associative selection color grey indicates a value that is:

  • A. Selected
  • B. Possible
  • C. Excluded (not associated) ✓
  • D. Calculated

Explanation: Grey = excluded: not associated with the current selection. Green = selected; white = possible. This associative feedback is a hallmark of Qlik analysis.

22. Which is a good practice when a KPI should stay fixed regardless of user filters?

  • A. Use set analysis with {1} or explicit modifiers ✓
  • B. Hide the KPI
  • C. Remove all filters from the app
  • D. Use a calculated dimension

Explanation: To make a measure ignore selections, use set analysis (e.g., {1} for all data, or modifiers that clear specific fields), fixing the calculation's scope independent of the current selection.

23. A treemap in Qlik Sense is best used to show:

  • A. Trends over time
  • B. Hierarchical part-to-whole relationships by area ✓
  • C. Correlation between two measures
  • D. A single KPI

Explanation: Treemaps display nested rectangles sized by a measure, good for part-to-whole across a hierarchy (e.g., region → category). Use line charts for trends and scatter for correlation.

24. The expression Rank(Sum(Sales)) in a chart returns:

  • A. The total sales
  • B. The rank of each dimension value by sales ✓
  • C. A running total
  • D. A percentage

Explanation: Rank() ranks the rows of a chart by the given expression, useful for top-N analysis and ordering dimension values by a measure.

25. A variable created with an input box lets users:

  • A. Change data in the source
  • B. Adjust a parameter (e.g., a target) that expressions reference dynamically ✓
  • C. Apply Section Access
  • D. Create a QVD

Explanation: Variables can be exposed via input controls so users set values (like a target or threshold) that expressions use — enabling what-if style interactivity.

26. A KPI that should turn red below target uses:

  • A. A conditional color expression (If ... red()) ✓
  • B. Section Access
  • C. A QVD
  • D. A crosstable

Explanation: Conditional coloring via an If() expression on the KPI's color attribute (e.g., If(measure<target, red(), green())) provides at-a-glance status.

27. The Aggr() function combined with Rank() is commonly used to:

  • A. Load QVDs
  • B. Compute top-N within groups (nested ranking) ✓
  • C. Apply Section Access
  • D. Concatenate tables

Explanation: Aggr() builds a per-group array that Rank() (or other aggregations) can operate on, enabling advanced calcs like ranking within categories or averaging per-group values.

28. The '$' set identifier means:

  • A. All records
  • B. The current selection ✓
  • C. The previous selection
  • D. Zero records

Explanation: {$} represents the current selection state; {1} is all records ignoring selection; {$1} would be the previous selection. Modifiers <> adjust fields within the chosen base set.

29. A pivot table is preferred over a straight table when you need to:

  • A. Show a flat list
  • B. Pivot dimensions across rows and columns and expand/collapse groups ✓
  • C. Only show one measure
  • D. Apply Section Access

Explanation: Pivot tables let you place dimensions on rows and columns with expandable groupings and subtotals — better for multidimensional exploration than a flat straight table.

30. To ensure all analysts use the same 'Net Revenue' definition, you should:

  • A. Ask everyone to retype it
  • B. Create a master measure ✓
  • C. Use a calculated dimension
  • D. Store it in a QVD

Explanation: A master measure centralizes the metric's definition so every chart references the same governed logic — preventing inconsistent variants of the metric.

31. The FirstSortedValue() function returns:

  • A. The last row
  • B. The value of one field corresponding to the sorted (e.g., smallest/largest) value of another ✓
  • C. A running total
  • D. All values

Explanation: FirstSortedValue(value, sortweight) returns the value associated with the first row after sorting by sortweight — e.g., the product with the highest sales (use -Sum(Sales) to sort descending).

  • A. Use many bright colors and 3D effects
  • B. Use consistent colors, clear titles, and sufficient contrast; avoid clutter ✓
  • C. Pack all measures on one sheet
  • D. Disable filters

Explanation: Clear titles, consistent and high-contrast colors, and uncluttered layouts improve readability and accessibility, helping users focus on the insights.

  • A. Possible and Excluded value sets of a field ✓
  • B. Percentages
  • C. QVD paths
  • D. Chart colors

Explanation: P(Field) is the set of possible values and E(Field) the excluded values given the current selection — useful in set expressions like Sum({<Customer=P(Customer)>} Sales).

34. A gauge chart is best used to show:

  • A. A trend over time
  • B. A single value against a range/target ✓
  • C. Correlation of two measures
  • D. Part-to-whole across categories

Explanation: A gauge displays one measure against a defined range or target (e.g., % of goal). For trends use a line chart; for comparisons use bars.

35. To compare selected vs unselected performance, a useful feature is:

  • A. Alternate states ✓
  • B. Section Access
  • C. QVD staging
  • D. Crosstable

Explanation: Alternate states let different objects respond to independent selections, enabling side-by-side comparison of two selection contexts within one app.
