QlikView 12 Business Analyst (QVBA) — Study Guide

Building analysis in QlikView: chart and expression design, set analysis, aggregation functions including Aggr(), drill-down/cyclic groups, list boxes and bookmarks, and UI/UX best practices.

~50 questions · 120 minutes · scenario-based on chart building and expressions · passing per Qlik scoring.

What it is

The QlikView 12 Business Analyst (QVBA) validates the ability to build analysis in QlikView: chart and expression design, set analysis, aggregation functions including Aggr(), drill-down and cyclic groups, list boxes and bookmarks, and UI/UX best practices.

It focuses on the analytical front end of QlikView — turning a data model into insightful, interactive charts and dashboards that answer business questions.

Where it's used

  • Roles: BI/Business Analyst, QlikView Report Developer, Analytics Consultant.
  • On the job: building charts and expressions, set-analysis measures (YoY, % of total), drill-down navigation, and executive dashboards.
  • Career value: validates the expression-building and visualization skills at the heart of effective QlikView analysis.
  • For this portfolio: reflects hands-on QlikView dashboard and KPI development across multiple industries.

In plain English

  • You build charts from dimensions (by what) and expressions (the calculation). Expressions are where the analysis lives.
  • The TOTAL keyword means 'ignore the chart's rows and give me the overall total' — the trick behind percentage-of-total.
  • Set analysis is a filter inside the formula: show this measure for 2024 (or last year) no matter what the user selected.
  • Aggr() builds a mini-table in memory (e.g., a total per customer) that you can then average or rank — for 'calculations on calculations.'

Exam shortcut tricks

  1. % of total = Sum(Sales)/Sum(TOTAL Sales). TOTAL ignores the chart's dimensions to give the overall/column total.
  2. Set identifiers: $ = current selection, 1 = all records. {$<Year={2024}>} starts from selection then forces Year; {1<...>} ignores selection.
  3. Aggr(expr, dim) for nested aggregation — Avg(Aggr(Sum(Sales),Customer)) = avg per customer; combine with Rank for top-N-per-group.
  4. Drill-down group = hierarchy (Year>Quarter>Month). Cyclic group = switch among unrelated dimensions. Different tools.
  5. FirstSortedValue(value, -weight): the '-' sorts descending, returning the top item (e.g., best-selling product).
  6. Prefer set analysis over row-level If() inside aggregations — the engine optimizes set analysis and it's faster.
  7. Dual(text, number) shows text but sorts by the number (e.g., month names in calendar order).

Study roadmap

  1. Requirements to design — turning business questions into charts and layouts.
  2. Dimensions & expressions — building measures with aggregation functions (Sum, Count, Avg, Min/Max).
  3. Set analysis — modifying selection scope inside expressions for comparisons and % of total.
  4. Advanced aggregation — Aggr() for calculating over a virtual dimension, and Total qualifier.
  5. Groups — drill-down groups (hierarchical) vs cyclic groups (switch dimensions).
  6. UI objects — list boxes, multi boxes, current selections, and bookmarks.
  7. Chart selection — right visualization for the analytical question.
  8. UX best practices — clarity, focused dashboards, and guided analysis.

Study notes

Expressions & aggregation

  • Chart measures are aggregation expressions evaluated per dimension value: Sum(Sales), Count(distinct Customer).
  • The TOTAL qualifier ignores chart dimensions (e.g., Sum(TOTAL Sales) gives the overall total for % calculations).
  • Aggr(expression, dimension) computes an inner aggregation over a virtual dimension — used for nested/advanced calcs like averaging a per-customer total.

Set analysis

  • Same syntax as Qlik Sense: Sum({<Year={2024}>} Sales); $ = current selection, 1 = all records.
  • Used for year-over-year, fixed baselines, and percentage-of-total measures.

Groups

  • Drill-down group: hierarchical (e.g., Year→Quarter→Month) — the chart drills as the user selects.
  • Cyclic group: lets the user cycle among unrelated dimensions in the same chart slot.

UI objects

  • List boxes show a field's values and selection state (green/white/grey).
  • Bookmarks save a set of selections to recall later; Current Selections box shows active filters.

Practice questions (100)

1. What does the TOTAL qualifier do in Sum(TOTAL Sales) within a chart?

  • A. Sums only the current row
  • B. Ignores the chart's dimensions and returns the overall total ✓
  • C. Applies Section Access
  • D. Creates a synthetic key

Explanation: TOTAL disregards the chart's dimensions so the expression returns the grand total across all dimension values — commonly used as the denominator in a percentage-of-total measure (Sum(Sales)/Sum(TOTAL Sales)).

2. When would you use the Aggr() function?

  • A. To load a QVD
  • B. To compute an aggregation over a virtual dimension, then aggregate that result (nested aggregation) ✓
  • C. To define Section Access
  • D. To create a bookmark

Explanation: Aggr() builds an intermediate array by evaluating an expression across a specified dimension, which you then aggregate — e.g., Avg(Aggr(Sum(Sales), Customer)) gives the average per-customer sales. It's the tool for nested/advanced calculations.

3. What is the difference between a drill-down group and a cyclic group?

  • A. They are identical
  • B. Drill-down is hierarchical (Year→Quarter→Month); cyclic lets users switch among unrelated dimensions ✓
  • C. Cyclic groups are for loading data
  • D. Drill-down groups only work in list boxes

Explanation: A drill-down group navigates a hierarchy level by level as the user selects. A cyclic group lets the user rotate among different, unrelated dimensions in the same chart dimension slot.

4. Which expression correctly computes each category's share of the overall total?

  • A. Sum(Sales)/Sum(Sales)
  • B. Sum(Sales)/Sum(TOTAL Sales) ✓
  • C. Sum(TOTAL Sales)/Sum(Sales)
  • D. Avg(Sales)

Explanation: Sum(Sales) is evaluated per dimension value while Sum(TOTAL Sales) ignores the dimension, so their ratio gives each category's percentage of the overall total.

5. What does a bookmark store in QlikView?

  • A. A chart image
  • B. A saved set of selections that can be recalled later ✓
  • C. A QVD file
  • D. A data model

Explanation: A bookmark captures the current selection state so users can return to a specific analysis context later — useful for saved views and sharing a particular filtered perspective.

6. Set analysis expression Sum({<Region=>} Sales) does what to the Region selection?

  • A. Keeps only the selected Region
  • B. Clears/ignores the Region selection for this aggregation ✓
  • C. Doubles the Region values
  • D. Causes an error

Explanation: An empty set modifier <Region=> removes the selection on Region for that expression, so it aggregates across all regions regardless of what's currently selected — handy for 'ignore this filter' measures.

7. Which chart is most suitable for showing the trend of sales over months?

  • A. Pie chart
  • B. Line chart ✓
  • C. Gauge
  • D. Straight table sorted by name

Explanation: A line chart best conveys change over a continuous time dimension, making trends and seasonality clear. Pie and gauge charts don't show change over time.

8. In a list box, a value shown in white after a selection means it is:

  • A. Selected
  • B. Associated/possible with the current selection ✓
  • C. Excluded
  • D. Calculated

Explanation: White = possible: the value is still associated with the current selection. Green = selected, grey = excluded. This associative feedback guides users through the data.

9. To display a measure that always shows last year's value next to the current selection, you would use:

  • A. A drill-down group
  • B. Set analysis with a year modifier ✓
  • C. A bookmark
  • D. An optimized QVD load

Explanation: Set analysis lets you fix or shift the year within the expression (e.g., <Year={$(=Max(Year)-1)}>) so a measure reflects last year independent of the user's current selection — the standard approach for period comparisons.

10. A dashboard is cluttered and users struggle to find insights. The best improvement is to:

  • A. Add more charts to every sheet
  • B. Focus each sheet on key questions, reduce clutter, and guide the analysis ✓
  • C. Remove all list boxes
  • D. Switch every chart to a table

Explanation: Good QlikView UX prioritizes clarity: focus sheets on the decisions users need, minimize clutter, and guide analysis with clear structure and selection objects — improving comprehension and adoption.

11. Which function gives the aggregated value across all dimensions in a chart for a % calculation?

  • A. Sum(TOTAL Sales) ✓
  • B. Sum(Sales)
  • C. Only(Sales)
  • D. Count(Sales)

Explanation: Sum(TOTAL Sales) ignores chart dimensions and returns the overall total, used as the denominator for percentage-of-total: Sum(Sales)/Sum(TOTAL Sales).

12. Aggr(Sum(Sales), Customer) produces:

  • A. A single total
  • B. An array of per-customer sales that can be further aggregated (e.g., averaged) ✓
  • C. A QVD
  • D. A bookmark

Explanation: Aggr() evaluates Sum(Sales) per Customer, yielding a virtual array you can wrap in another aggregation, e.g., Avg(Aggr(Sum(Sales),Customer)) for average sales per customer.

13. A cyclic group in a QlikView chart lets users:

  • A. Drill down a hierarchy
  • B. Cycle among unrelated dimensions in the same chart slot ✓
  • C. Apply Section Access
  • D. Create a QVD

Explanation: A cyclic group rotates through a set of unrelated dimensions (e.g., Region, Product, Channel) in one chart, letting users switch the view without separate charts. A drill-down group navigates a hierarchy.

14. The expression Sum({1} Sales) returns:

  • A. Sales for the current selection
  • B. Sales for all records ignoring selections ✓
  • C. Zero
  • D. Only selected products

Explanation: The set identifier {1} means all records regardless of selection, so Sum({1} Sales) is the grand total. {$} would respect the current selection.

15. A straight table differs from a pivot table in that it:

  • A. Cannot show measures
  • B. Displays a flat, row-per-record style grid without dimensional pivoting ✓
  • C. Is only for dates
  • D. Requires Section Access

Explanation: A straight table shows a flat grid (sortable columns), while a pivot table lets you pivot dimensions across rows/columns and expand/collapse groupings.

16. The Only() function returns a value when:

  • A. There are multiple distinct values
  • B. There is exactly one possible value for the expression's scope (else null) ✓
  • C. The table is empty
  • D. Always

Explanation: Only() returns the single value if the aggregation scope resolves to exactly one distinct value; otherwise it returns null — useful to display a field value when uniquely determined by selection.

17. To show last year's sales next to the current year regardless of selection, use:

  • A. Set analysis with a year modifier per measure ✓
  • B. A drill-down group
  • C. A bookmark
  • D. Section Access

Explanation: Two measures each using set analysis to fix their year (e.g., <Year={$(=Max(Year))}> and <Year={$(=Max(Year)-1)}>) display current vs prior year independent of the user's selection.

18. Conditional coloring of a chart expression (e.g., red if below target) is done with:

  • A. An If() expression in the color/background attribute ✓
  • B. A QVD
  • C. Section Access
  • D. IntervalMatch

Explanation: QlikView chart expressions support attribute expressions such as background color, where an If() test (e.g., If(Sum(Sales)<Target, red(), green())) drives conditional formatting.

19. A bookmark in QlikView is best described as:

  • A. A saved chart image
  • B. A saved set of selections that can be recalled and shared ✓
  • C. A QVD file
  • D. A data model

Explanation: A bookmark captures the current selection state so users can quickly return to a specific analysis context and share it with others.

20. Which is the correct way to compute a share ignoring only the Product selection?

  • A. Sum(Sales)/Sum({<Product=>} TOTAL Sales) ✓
  • B. Sum(Sales)/Sum(Sales)
  • C. Avg(Sales)
  • D. Only(Sales)

Explanation: The modifier <Product=> clears the Product selection for the denominator, and TOTAL removes chart dimensions, giving each product's share of the all-products total.

21. The Dimensionality() function is useful in a pivot table to:

  • A. Count records
  • B. Determine the current level of aggregation (number of active dimensions) for conditional logic ✓
  • C. Create a QVD
  • D. Apply Section Access

Explanation: Dimensionality() returns how many dimensions are in play at the current row, letting you vary an expression at subtotal vs detail levels in pivot tables.

22. Which chart is best for showing correlation between two measures across items?

  • A. Scatter chart ✓
  • B. Gauge
  • C. Single KPI
  • D. Pie chart

Explanation: A scatter chart plots two measures on x/y with a point per item (bubble size can add a third), revealing correlation, clusters, and outliers.

23. Best practice when a QlikView document is slow to render charts is to:

  • A. Add more expressions to each chart
  • B. Simplify expressions, reduce distinct values, and precompute in the script where possible ✓
  • C. Remove all list boxes
  • D. Disable bookmarks

Explanation: Chart performance improves by simplifying/rewriting heavy expressions, reducing cardinality, and moving calculations into the load script (flags, pre-aggregations) so the UI does less work.

24. The Rank() function inside a chart expression is used to:

  • A. Load a QVD
  • B. Rank rows by an expression (for top-N and ordering) ✓
  • C. Apply Section Access
  • D. Concatenate tables

Explanation: Rank(expression) ranks the chart's rows by the expression, enabling top-N highlighting, ordering, and conditional logic based on position.

25. A gauge chart in QlikView is best for:

  • A. A single KPI vs a target/range ✓
  • B. Trends over time
  • C. Correlation
  • D. Detailed record lists

Explanation: Gauges display one value against a defined range or target. For trends use line charts; for record detail use straight/pivot tables.

26. The set expression Sum({$<Year={2024}>} Sales) does what?

  • A. Ignores all selections
  • B. Starts from the current selection but forces Year to 2024 ✓
  • C. Returns zero
  • D. Loads a QVD

Explanation: {$<...>} begins with the current selection ($) and applies the modifier — here overriding Year to 2024 while respecting other current selections.

27. Which enables users to switch a chart's dimension among several options?

  • A. A cyclic group ✓
  • B. A drill-down group
  • C. Section Access
  • D. A QVD

Explanation: A cyclic group lets the user rotate among unrelated dimensions in one chart. A drill-down group instead navigates a hierarchy from summary to detail.

28. Total qualifier with a field, e.g., Sum(TOTAL <Region> Sales), computes the total:

  • A. Across all rows ignoring every dimension
  • B. Within each Region (grouping by the specified field only) ✓
  • C. Per individual row

Explanation: TOTAL <Region> restricts the total to be computed per Region (ignoring other chart dimensions), useful for share-within-group calculations.

29. A text object with an expression is commonly used to:

Explanation: Text objects can show computed expressions (e.g., a headline KPI or contextual message), with conditional formatting — handy for dashboards and callouts.

Explanation: Num()/Money() format numbers for presentation (e.g., Num(Sum(Sales),'#,##0') or Money(...)), improving readability without altering underlying values.

31. Which function returns a value only when a single value remains after selection?

  • B. Sum()

  • C. Only(Sales)

35. Best practice when an expression is reused across many charts is to:

  • D. Requires Section Access

Explanation: A stacked bar shows the total per category with segments for composition; a grouped bar places series side by side for direct comparison of each series across categories.

  • B. The maximum
  • C. A QVD
  • D. A synthetic key

  • C. Invalid

Explanation: Row-level If() inside aggregations works but is typically slower than equivalent set analysis, which the engine optimizes better for filtering scopes.

  • C. Rank(Sales)
  • D. Above(Sales)

Explanation: Max(Sales) aggregates to the largest value in scope. Only returns a value when unique; Rank ranks; Above references other rows.
